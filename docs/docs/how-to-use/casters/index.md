# Manipulação de Dados (Casters)
{: .no_toc }

A biblioteca `laravel-br-helper` provê Casters customizados para formatar de forma elegante os dados brasileiros ao utilizá-los no Eloquent. 
Para todos os casters, se você utilizar a opção padrão (ex: `CepCast::class`), o tipo de armazenamento no banco de dados é inferido como `DBType::STRING`.

Acesse as páginas de cada caster no menu lateral para visualizar detalhes, exemplos de uso e opções.
